# はじめに

Muu IME は、macOS の日本語入力メソッドです。変換は端末の中だけで行い、変換の内容をどこかへ送ることはありません。

- macOS とのやり取り（キーの受け取り、未確定文字列と候補の表示、ファイルの保存）は Swift と InputMethodKit で書かれています。
- 変換（ローマ字からかなへ、文節、候補、辞書、学習）は Rust で書かれ、小さな C ABI でつながっています。
- 変換は辞書から候補を作り、必要に応じて言語モデルで第一候補を選び直します。言語モデルは利用者が明示的に取得したときだけ使います。
- ユーザー辞書、取り込んだ辞書、郵便番号データ、変換学習は、利用者の Mac の中に保存されます。

対応環境は **Apple Silicon の Mac、macOS 15 以降** です。

この文書は次の 3 部に分かれています。

- [インストール](./install.md): ビルド、インストール、更新とアンインストール。
- [使い方](./usage/input.md): 入力の操作、辞書や学習の管理、困ったときの確認。
- [仕組み（開発者向け）](./internals/design-principles.md): 設計の考え方、構成、変換の流れ、保存形式、C ABI、ビルドとテスト。今のコードの契約と、決めたことの理由を書きます。
