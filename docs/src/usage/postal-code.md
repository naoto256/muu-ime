# 郵便番号データ

郵便番号を変換すると、都道府県・市区町村・町域の住所が候補に出ます。データは日本郵便の公開データで、最初から app に入っています。

## 変換のしかた

- `1000001`、`100-0001`、全角の `１０００００１`、`１００－０００１` のどれでも、同じ郵便番号として扱います。かなの入力中は `-` キーが `ー` になるので、`3 桁＋ー＋4 桁` の形のときだけ郵便番号として扱います。
- 同じ郵便番号に複数の町域があるときは、公式データの順に候補にします。
- 「以下に掲載がない場合」などの場合は、市区町村までを出します。

## 更新する

IME メニューの **郵便番号データ…** を開くと、「Muu 郵便番号データ」のウインドウが出ます。配布版、取得日時、収録件数、検証済みのデータの SHA-256 を確認できます。

- **郵便番号データを更新…** を押すと、日本郵便の公式サイトから最新のデータを取得します。Muu が通信するのはこの操作のときだけで、自動の更新はしません。
- 取得したデータは検証してから切り替えます。取得や検証に失敗したときは、いまのデータを使い続けます。
- **日本郵便の配布ページを開く** で配布元のページを、**データフォルダを表示** で保存先を開けます。

保存先は `~/Library/Application Support/dev.muu.inputmethod.Muu/postal_code/v1/` です。データの出所とライセンスは [ライセンスと既知の制限](../internals/licenses-and-limitations.md)。
