# 辞書の取り込み

ほかで作った辞書を、ファイルから取り込んで使えます。IME メニューの **辞書の管理…** を開くと、「Muu 辞書管理」のウインドウが出ます。辞書はファイルから取り込むだけで、ネットワークから取得することはありません。

## 取り込める形式

- **Muu 辞書（`.muudict`）**: Muu の交換用の形式です。**ひな形を書き出す…** で、書き方の例を保存できます。
- **Google 日本語入力（Mozc）の辞書のテキスト**: UTF-8 のタブ区切り（BOM があってもかまいません）。品詞の日本語名は Muu の品詞に対応付けます。

1 行でも不正な行があると、その辞書は取り込みません。

## 操作

- **辞書を取り込む…** でファイルを選びます。内容と辞書の情報（名前、版、作者、ライセンス、由来）を確かめてから取り込みます。
- 一覧では、辞書ごとに **使用**（有効・無効）、辞書名、バージョン、件数、状態が出ます。選んだ辞書の作者、ライセンス、由来、取り込んだ日時、SHA-256 も表示します。
- 同じ辞書 ID の辞書をもう一度取り込むと、確かめたうえで辞書全体を置き換えます。
- **削除** で辞書を消します。

取り込んだ語は、ユーザー辞書の語より弱く、郵便番号と内部の辞書の語より強く扱います。

## 上限

1 つの辞書は 100,000 件・16 MiB まで、辞書は 32 個まで、有効な辞書の合計は 250,000 件まで、活用を展開したあとの合計は 1,000,000 まで。

## 問題があるとき

- 保存しているファイルが読めないときは読み取り専用になり、保存も掃除もしません。
- 上限に当たるときは、一覧はそのまま表示しますが変換には使わず、「辞書を有効にできないため、まず削除または無効化で直してください。」と出ます。
- 取り込みのあとの保存と反映に失敗して整合を取り戻せない場合は、Muu を終了します。次に入力したときに、ディスクに保存されている内容から起動し直します。

保存先は `~/Library/Application Support/dev.muu.inputmethod.Muu/imported_dict/v2/` です。
