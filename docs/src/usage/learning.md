# 変換学習と削除

Muu は、候補を選んで確定した結果から学習し、次からの候補の順を調整します。

## 何を学習するか

- 文節の候補を自分で選んで確定した語は、上がりやすくなります。
- 候補を替えて確定したとき、替える前の第一候補だった語は、同じ範囲では下がりやすくなります。
- 言語モデルを使っているときは、学習した語を含む候補が選ばれやすくなります。
- ユーザー辞書、取り込んだ辞書、郵便番号の語は学習の対象外です。
- 回数には上限があり、古い学習は少しずつ薄れます。文脈で使い分ける語では、学習しても候補が揺れることがあります。

保存するのは、内部の辞書の語の番号と回数だけです。読み、表層、時刻、アプリの情報は保存しません。学習は、使っているシステム辞書に結び付きます。別の辞書の版に変わると、その学習は使わず空から始めます。

保存先は `~/Library/Application Support/dev.muu.inputmethod.Muu/personal_frequency/personal-frequency-v1.json` です。最後の更新から 250 ms 後にまとめて保存します。

## 削除する

IME メニューの **変換学習データを削除…** を選ぶと、「変換学習データを削除しますか？」と確かめます。**削除** を押すと、学習による調整をすべて消し、辞書本来の変換順に戻します。

| 表示 | 意味 |
|---|---|
| （何も出ない） | 削除しました。 |
| 変換学習データを削除できませんでした | 現在の学習は変わっていません。 |
| 変換学習データを削除しました（耐久性を確認できませんでした） | 削除は完了しましたが、ディスクへの書き込みを確かめられませんでした。 |
| 変換学習データを削除しました（動作中の変換には反映できませんでした） | 保存していた学習は消しましたが、動いている Muu には反映できませんでした。入力メソッドを再起動すると、空の学習から始まります。 |

起動時に読めなかった学習ファイルを退避したもの（`personal-frequency-rejected-*.json`）も、削除のときに一緒に消します。

## 保存が止まるとき

保存先が安全でない場所だった場合や、学習の内容が保存の上限を超えた場合などは、その起動の間は保存を止めます。About の「学習」の行に理由が出ます。学習の削除に成功すると、保存を再開します。
