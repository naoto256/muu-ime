# 変換モデル

Muu は、辞書から作った候補のうち第一候補を、言語モデルで選び直すことができます。使うモデルは zenz-v3.2-small（約 74 MB）です。モデルは Muu に同梱しておらず、利用者が取得したときだけ使います。

## 取得する

1. IME メニューの **About Muu IME** を開きます。
2. 「モデルの取得」の行が「未取得（約74 MB）」なら、**取得** を押します。
3. 取得中は「取得中（N%）」、そのあと「照合中」と出ます。途中で **中止** できます。
4. 取得と照合が済むと、「完了（再起動待ち）」になり、**Muu IME を再起動** のボタンが出ます。押すと Muu を終了し、次に入力したときから zenz を使います。

- 取得するのは、版と SHA-256 を固定した 1 つのファイルだけです。通信するのはこの取得の操作をしたときだけで、自動では取得しません。
- 失敗したときは理由（「通信に失敗しました」「照合に失敗しました」など）が出て、**再試行** できます。
- 取得したモデルは `~/Library/Application Support/MuuIME/Models/zenz-v3.2-small/` に置かれます。
- 使っている間は「取得済み・利用中」と出ます。

## 使わない場合

モデルを取得しなくても、Muu は辞書だけで変換します。このとき、言語モデルによる選び直しは行いません。モデルがない状態では、About の「言語モデル」が「なし」になり、メニューの About の項目に印（⚠︎）が付いたままになります。

zenz が見つからないか読み込めないときも、モデルなしで動きます（ほかのモデルへ黙って切り替えることはしません）。
