# 入力の基本

## 入力ソース

入力ソースは 2 つです。

- **Muu IME ひらがな**: ローマ字で日本語を入力します。
- **Muu IME 英数**: 英数字を入力します。

ローマ字の表は Muu が独自に作ったものです。

## 変換と確定

| キー | 動作 |
|---|---|
| Space | 変換する。変換中は次の候補 |
| Shift+Space、↑ | 前の候補 |
| ↓ | 次の候補 |
| ←、→ | 変換前: カーソルを 1 文字ずつ動かす（端では止まる）。変換後: 文節を移動する |
| Shift+←、Shift+→ | 変換後: 文節を縮める・伸ばす |
| Return | 全体を一度に確定する（変換の前でも後でも。文節ごとには確定しない） |
| Esc | 取り消す |
| Delete | カーソルの直前の 1 文字を消す（かなを消してローマ字の途中に戻ることはない）。変換中の最初の Delete は、変換だけを解除して読みに戻す（文字は消さない） |

- 変換中に次の文字を打つと、いまの候補で全体を確定し、その文字から新しい入力を始めます。変換を取り消して読みに戻ることはありません。
- 変換前に文字の途中へカーソルを動かして打つと、その位置に挿入します。
- 数字のキーで候補を選ぶことはできません。
- 候補の一覧は、カーソルの近くに縦 8 行ずつ出ます。クリックで選び、ダブルクリックで確定します。
- かなの入力中に打った ASCII の記号は、日本語の表記で未確定文字列に入り、その場では確定しません。変換すると、日本語の表記が第 1 候補、打った記号が第 2 候補になります。
- 記号は「きごう」などの読みで、顔文字は「かおもじ」、絵文字は「えもじ」で全件を候補に出せます。単漢字は、読みが完全に一致したときに候補の末尾へ加わります。

## 英字をそのまま入れる（Shift）

- **Shift を押しながら英字を打つ**と、そこから英字のままの入力（Literal）になります。Literal の間の Space は変換を始めず、空白を入れます。
- Literal の入力中に **Esc** を 1 回押すと、入力した文字を保ったままかなの入力に戻ります。もう 1 回押すと取り消します。
- **Shift だけを押して離す**と、かなの入力と Literal を切り替えます。空の状態からでも切り替えられるので、小文字で始まる英字（`npm` など）もそのまま入れられます。変換中とひらがな以外のモードでは何も起きません。

切り替わると、カーソルの近くに `A`（Literal）または `あ`（かな）が約 1 秒出ます。候補が出ているときや、アプリがカーソルの位置を正しく返さないときは出ません（切り替え自体は行われます）。

アプリによっては Shift だけの操作が Muu に届きません。その場合も、Esc（かなへ戻る）と Shift+英字（Literal を始める）はどのアプリでも使えます。

## そのほか

- 割り当てのない Cmd・Ctrl・Option の組み合わせと F キーは、入力中は何もせずに受け取り、入力していないときはアプリへ渡します。
- Tab や、日本語以外の文字のキーなどは、入力中の文字を確定してからアプリへ渡します。
- Cmd+Space が macOS の入力ソースの切り替えに割り当てられていると、そのキーは Muu に届かず、入力中の文字は確定されます。
- 郵便番号（`1000001` や `100-0001`）を変換すると、住所の候補が出ます（[郵便番号データ](./postal-code.md)）。
