# ユーザー辞書

自分で語を登録する辞書です。IME メニューの **ユーザー辞書…** を開くと、「Muu ユーザー辞書」のウインドウが出ます。

## 登録と変更

- **よみ**（ひらがな）、**単語**、**品詞**、**優先度**（高・標準・低）を入れて **追加** を押します。
- 一覧で選んだ語は、内容を変えて **更新**、または **削除** できます。
- **辞書ファイルを表示** で、保存しているファイルを Finder に表示します。

登録した語は、次の変換から使われます。登録した語が第一候補になっている文節は、言語モデルによる選び直しで別の候補に替えられません。

品詞は一覧から選びます。「サジェストのみ」の語は保存されますが、変換には出ません（予測入力の機能ができたら使います）。ウインドウの件数の表示にも、その旨が出ます。

## 上限

- 10,000 語まで。ファイルは 8 MiB まで。よみは 512 bytes、単語は 4 KiB まで。
- 1 つのよみに登録できる単語は 4,096 個まで。

## 辞書ファイルに問題があるとき

- **ファイルの形式が読めない**とき（ヘッダや列の不正、壊れた行、上限を超える件数など）は、読み取り専用になります。画面からは直せないので、ファイルを置き換えてください。Muu が元のファイルを書き換えることはありません。
- **形式は読めるが上限に当たる**とき（1 つのよみに単語が多すぎるなど）は、一覧はそのまま表示しますが、変換には使いません（About の「ユーザー辞書」が「層は空（縮退）」になります）。このときは削除だけができ、「辞書が上限を超えているため、まず削除で直してください。」と出ます。上限に収まると、また変換に使われます。
- 保存の途中でディスクの書き込みを確かめられなかったときは、「保存の耐久性を確認できませんでした」と出ます。
- 保存のあとで変換への反映に失敗し、元の内容にも戻せなかったときは、編集を止めます。このとき、元の内容は同じフォルダの `user-dictionary.recovery-<番号>.tsv` に残します。このファイルは自動では読み込みません。

## ファイルの形式

保存先は `~/Library/Application Support/dev.muu.inputmethod.Muu/user_dict/user-dictionary.tsv` です。1 行目が `# muu-user-dictionary\t1`、以降の各行が `よみ\t単語\t品詞\t優先度\tCRC32` の UTF-8 のテキストです（[データの保存](../internals/storage.md)）。
