# データと通信

## 保存する場所

ユーザーデータは、すべて利用者の Mac の中に保存します。

| データ | 場所（`~/Library/Application Support/` の下） |
|---|---|
| ユーザー辞書 | `dev.muu.inputmethod.Muu/user_dict/` |
| 取り込んだ辞書 | `dev.muu.inputmethod.Muu/imported_dict/v2/` |
| 郵便番号データ | `dev.muu.inputmethod.Muu/postal_code/v1/` |
| 変換学習 | `dev.muu.inputmethod.Muu/personal_frequency/` |
| 変換モデル | `MuuIME/Models/<モデル名>/` |

- フォルダは本人だけが読み書きできる権限（0700）、ファイルは 0600 で作ります。
- 書き込みは一時ファイルに書いて置き換える方法で行い、途中で失敗しても前の内容が残るようにしています。
- アンインストールしても、これらのデータは消しません。

システム辞書と郵便番号の初期データは app に同梱しています。キー割り当てとローマ字の表は Muu に組み込まれていて、差し替えるファイルはありません。

## 通信

Muu が通信するのは次の 2 つだけで、どちらも利用者の操作で始まります。

| 場面 | 通信先 |
|---|---|
| 郵便番号データの更新（「郵便番号データを更新…」） | 日本郵便の公式サイト |
| 変換モデルの取得（About の **取得**） | Hugging Face の、版を固定した zenz-v3.2-small のファイル |

自動の更新、バックグラウンドの通信、使用状況や入力の送信はありません。辞書の取り込みはファイルからだけです。

## 記録について

変換を後から調べるための記録（読みと確定した文字列を平文で残すもの）は、開発用の dogfood 版でだけ使えます。配布する版では、設定を変えても有効になりません（About の「記録」は「無効（配布ビルド）」）。理由は [ビルドとテスト](../internals/build-and-test.md) の「配布版と dogfood 版」にあります。
