# About の見方

IME メニューの最後の **About Muu IME** で、Muu の版と各データの状態を確認できます。開いた時点の状態を表示します。

何か異常があるときは、メニューの項目が **⚠︎ About Muu IME** になります。状態を問い合わせられなかっただけの「状態不明」では印は付きません。

## 行の意味

| 行 | 主な表示 |
|---|---|
| バージョン、コミット | Muu の版、ビルド番号、元のソースのコミット |
| Core | 利用可／初期化失敗／利用できません（再起動が必要） |
| システム辞書 | 利用可／かなだけで動作 |
| 言語モデル | 読み込み済み（モデル名）／読み込み中／なし／読み込み失敗 |
| ユーザー辞書、取り込み辞書、郵便番号 | 利用可、未登録、読み込み中、読み取り専用、層は空（縮退）、編集停止（再起動が必要）、保存の耐久性に警告あり など |
| 学習 | 利用可、または保存を止めた理由（安全でない保存先・保存停止 など） |
| 学習の最終保存 | 最後に保存した時刻、保存ファイルなし、消去済み など |
| 学習の保存状態 | 保存済み／保存待ち／保存失敗・再試行待ち／保存済み・耐久性の警告あり など |
| 記録 | 配布版では「無効（配布ビルド）」 |
| モデルの取得 | 変換モデルの取得の状態とボタン（[変換モデル](./conversion-model.md)） |

- 「言語モデル」が「なし」のとき（モデルを取得していないとき）は、印が付いたままになります。
- 「取り込み辞書」の「未登録」は、辞書がない、またはすべて無効の状態で、異常ではありません。
- 下の方には、言語モデルのライセンスの表示（名称、ライセンス、詳細は同梱の NOTICE）が出ます。

## ボタン

- ふだんは **閉じる** だけです。
- 変換モデルを取得していないときは **取得** と **閉じる** が出ます。横並びでは、左が **取得**、右が **閉じる** です。Return を押したときは **閉じる** になります。
- 取得が済んで再起動すると使えるようになるときは、**Muu IME を再起動** だけが出ます。Return では何も起きず、Esc で閉じます。
